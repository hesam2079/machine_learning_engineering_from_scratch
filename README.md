# Machine Learning Engineering From Scratch

A hands-on journey from zero to machine learning engineer. Every concept and every project here is built **from scratch** — by hand, without AI-generated code.

> **The rule:** I write every line of code myself. No copy-paste, no AI assistance. If I don't understand it, I relearn it until I do.

## 🗺️ Roadmap

### Phase 1 — Foundations
- [ ] Python for data science (NumPy, Pandas, Matplotlib)
- [ ] Math refresh: linear algebra, calculus, probability & statistics

### Phase 2 — Classical Machine Learning
- [ ] Linear & logistic regression from scratch (NumPy only, no libraries)
- [ ] KNN, decision trees, SVM, k-means (from scratch, then with scikit-learn)
- [ ] Model evaluation: metrics, cross-validation, bias/variance, hyperparameter tuning

### Phase 3 — Deep Learning
- [ ] A neural network from scratch (NumPy forward pass + backprop)
- [ ] PyTorch fundamentals: tensors, autograd, training loops
- [ ] CNNs for image tasks, RNN/Transformer basics for text

### Phase 4 — ML Engineering & MLOps
- [ ] Structured project layout (data → model → evaluation → API)
- [ ] Packaging, testing, and versioning models
- [ ] Docker, serving with FastAPI, basic CI/CD
- [ ] Experiment tracking and monitoring

## 🚀 How to use this repo

1. Pick the next item on the roadmap.
2. Create a new project folder: `projects/NN-name/`.
3. Build it from scratch, commit often (small, meaningful commits).
4. Finish by writing the project's `README.md`: goal, approach, what broke, what I learned.
5. Update the project table and tick the roadmap box here.
